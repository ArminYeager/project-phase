# Requirement Specification: ระบบข้อมูลภาพยนตร์ (Movie Catalog System)

รหัสนิสิต: 67160042 | Pno = 3

## 1. ชื่อระบบและวัตถุประสงค์

**ชื่อระบบ:** Movie Catalog System (ระบบข้อมูลภาพยนตร์)

**วัตถุประสงค์:** เก็บข้อมูลภาพยนตร์ ผู้กำกับ ค่ายผู้สร้าง และแนวหนัง เพื่อใช้เป็น backend
ของแอปพลิเคชันรีวิว/แนะนำภาพยนตร์ หรือระบบจัดการคลังข้อมูลภาพยนตร์

**ปัญหาที่ระบบแก้ไข:**
- ข้อมูลภาพยนตร์/ผู้กำกับ/ค่ายผู้สร้างถูกเก็บกระจัดกระจาย ไม่มีมาตรฐานกลาง
- ผู้ใช้ค้นหาภาพยนตร์ตามแนวหนัง หรือดูผลงานทั้งหมดของผู้กำกับคนหนึ่งไม่สะดวก
- ไม่มีการบังคับความถูกต้องของข้อมูลที่ระดับฐานข้อมูล เช่น ภาพยนตร์ต้องมีผู้กำกับที่มีอยู่จริงเสมอ

**กลุ่มผู้ใช้เป้าหมาย:**
1. ผู้ใช้ทั่วไป — ค้นหาและเรียกดูข้อมูลภาพยนตร์ ผู้กำกับ แนวหนัง
2. ผู้ดูแลระบบ — เพิ่ม/แก้ไข/ลบข้อมูลภาพยนตร์ ผู้กำกับ ค่ายผู้สร้าง และกำหนดแนวหนัง

## 2. รายการ Use Case หลัก

| # | Use Case | ผู้กระทำ |
|---|----------|----------|
| 1 | ค้นหาภาพยนตร์จากชื่อเรื่องหรือชื่อผู้กำกับ | ผู้ใช้ทั่วไป |
| 2 | ดูรายชื่อภาพยนตร์ทั้งหมดของผู้กำกับคนหนึ่ง | ผู้ใช้ทั่วไป |
| 3 | ดูรายละเอียดภาพยนตร์พร้อมแนวหนังทั้งหมด | ผู้ใช้ทั่วไป |
| 4 | เพิ่ม/แก้ไข/ลบข้อมูลผู้กำกับ | ผู้ดูแลระบบ |
| 5 | เพิ่มภาพยนตร์ใหม่พร้อมกำหนดค่ายผู้สร้าง | ผู้ดูแลระบบ |
| 6 | กำหนดแนวหนัง (genre) ให้กับภาพยนตร์แต่ละเรื่อง | ผู้ดูแลระบบ |
| 7 | กรองภาพยนตร์ตามค่ายผู้สร้าง | ผู้ใช้ทั่วไป |

## 3. รายการ Resource หลักและความสัมพันธ์

| Resource | คำอธิบาย | ฟิลด์หลัก |
|----------|----------|-----------|
| `directors` | ผู้กำกับภาพยนตร์ | director_id, name, nationality, birth_year |
| `studios` | ค่ายผู้สร้าง | studio_id, name, country |
| `movies` | ภาพยนตร์ | movie_id, title, director_id (FK), studio_id (FK), release_year, duration_minutes |
| `genres` | แนวหนัง | genre_id, name |
| `movie_genres` | ตารางเชื่อม ภาพยนตร์↔แนวหนัง | movie_id (FK), genre_id (FK) |

**ความสัมพันธ์:**
- `directors` 1 --- * `movies` (ผู้กำกับคนหนึ่งกำกับได้หลายเรื่อง)
- `studios` 1 --- * `movies` (ค่ายหนึ่งผลิตได้หลายเรื่อง)
- `movies` * --- * `genres` (หนังเรื่องหนึ่งมีได้หลายแนว ผ่านตารางเชื่อม `movie_genres`)
